# Issue Tracker

Issues are tracked in **GitHub Issues** for the `trdong19/ClipSync` repository.

## Commands

Use the `gh` CLI for all issue operations:

- List issues: `gh issue list`
- Create issue: `gh issue create`
- View issue: `gh issue view <number>`
- Edit issue: `gh issue edit <number>`
- Close issue: `gh issue close <number>`
- Add labels: `gh issue edit <number> --add-label <label>`
- Add assignees: `gh issue edit <number> --add-assignee <user>`
- Comment: `gh issue comment <number>`

## Notes

- The repo is at `https://github.com/trdong19/ClipSync`
- Use English for issue titles and descriptions for broader accessibility
- Chinese is acceptable for internal discussions
